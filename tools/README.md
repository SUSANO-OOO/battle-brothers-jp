# Tooling

`bbjp.py` currently provides:

- `scan`: capture an evidence-backed installed snapshot and pre/post read-only tree audit.
- `extract`: copy selected archive code/text only into ignored `work/` paths with ZIP-slip protection.

Planned commands are `diff`, `coverage`, `validate`, `build`, `qa`, and `update`. Raw installed inputs and derived proprietary source remain under ignored `work/` paths.
